## Eventore — *One console for every stream*

Open-source **multi-protocol streaming console** — Kafka, Pulsar, RabbitMQ, MQTT, JMS, Kinesis, GCP Pub/Sub, Azure Service Bus. Spring Boot control plane, React UI, Helm/K8s deploy, optional MCP for AI agents.

- Live WebSocket streaming · ADMIN / DEV / READONLY modes · GHCR images + OCI Helm charts
- [Product docs](https://vijayptiwari.github.io/eventore/) · [GitHub](https://github.com/vijayptiwari/eventore)

```bash
helm install eventore oci://ghcr.io/vijayptiwari/charts/eventore --version 0.1.0 \
  -f deploy/helm/eventore/values-stream-kafka.yaml
```

## Meridian — *Align your next move*

Open-source **local-first AI career agent** — job search, fit scoring, resume tailoring, upskilling, and career transitions. Runs on your machine; no cloud upload; BYOK LLM.

- Multi-agent pipeline · Playwright portals · checkpoint resume · demo mode
- [Live docs](https://vijayptiwari.github.io/meridian/) · [GitHub](https://github.com/vijayptiwari/meridian)

```bash
git clone https://github.com/vijayptiwari/meridian.git && cd meridian
npm install && npm run ui
```
