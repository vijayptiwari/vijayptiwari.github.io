Cloud Data Security using DNA Cryptography Techniques

A forward-looking exploration of molecular computation and DNA-inspired encoding for protecting data in cloud systems.

Vijay Prakash Tiwari · Akshay Bapusaheb Patil · Avinash Murlidhar Ingole

Paper focus

Could DNA-inspired computation expand the cloud-security design space?

The paper begins with the growth of cloud-hosted text, image, and video data and the corresponding pressure on encryption systems. It then examines DNA computing as a possible source of high-density information representation and parallel processing.

It proposes an encoding and decoding sequence built around binary-to-DNA-base mappings and reports a Python execution-time simulation across increasing message sizes. The work connects molecular-computing ideas with a practical security problem, while stopping short of a production cloud deployment or formal security proof.

Key themes

Security, density, and parallelism

  • Cloud adoption makes confidentiality and scalable data protection first-order system concerns.
  • DNA represents information using nucleotide bases, opening a different encoding vocabulary from conventional binary storage.
  • Molecular computation was considered for massive parallelism and compact data representation.
  • The proposed direction depends on future implementation feasibility, performance evidence, and cryptanalysis.

Reading it today

A historical proposal with simulation—not a validated security primitive

The paper captures an early engineering interest in combining domains that were usually discussed separately: cloud infrastructure, cryptography, and molecular computation. The included simulation measures implementation timing, but does not demonstrate cryptographic strength.

Claim boundary

This archive does not present DNA cryptography as production-proven or inherently more secure. Any modern implementation would require a precise threat model, reproducible benchmarks, independent cryptanalysis, and evidence against established alternatives.
